# Sanklean

> A cleaner alternative to creating Sankey diagrams rather than coding or using Excel.

## What

Sanklean is a simple, interactive Sankey diagram whiteboard that lets users create and edit flow diagrams directly on a canvas.

## Why

Creating Sankey diagrams often requires coding, spreadsheets, or cumbersome diagramming tools.

Sanklean is intended to make the process visual and direct: create nodes, connect flows, edit values, and arrange the diagram directly on the canvas.

## How

- Use the Hand tool as the primary way to interact with the canvas.
- Create and edit nodes directly.
- Set node values directly.
- Connect nodes to create flows.
- Move nodes freely around the canvas.
- Use the Selector when selecting groups of elements for deletion.
- Use Clear All only when you want to remove the entire diagram.

## Setup

```bash
git clone https://github.com/SASU004/Sanklean.git
cd Sanklean
npm install
npm run dev
```
